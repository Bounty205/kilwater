# Килватер

Погода для паруса на открытых данных: ветер, зыбь, течение, уровень моря,
сравнение моделей, ансамбль ECMWF и расчёт перехода по полярам ORC.

Одна страница без сборки. Данные — Open-Meteo поверх ECMWF IFS, GFS и ICON;
волна — WaveWatch III и ECMWF WAM. Карта — OpenStreetMap плюс знаки OpenSeaMap.

Это планировщик, а не навигация.
